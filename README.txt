MY DREAM GAME SHOP — ระบบเช่าเครื่องเกมรายเดือน

ฟีเจอร์:
- แพ็กเกจเครื่องเกม PS5 รายเดือน
- ราคาเริ่มต้น 800 บาท/เดือน
- เลือกระยะเวลา 1 / 3 / 6 / 12 เดือน
- คำนวณยอดรวมอัตโนมัติ
- กรอกชื่อและช่องทางติดต่อ
- ส่งรายละเอียดการสมัครเข้า LINE @edsakit
- สร้างเลขรายการอัตโนมัติ

ตัวอย่างราคา:
1 เดือน = 800 บาท
3 เดือน = 2,400 บาท
6 เดือน = 4,800 บาท
12 เดือน = 9,600 บาท

วิธีอัปเดต GitHub Pages:
1. เปิด Repository เดิม
2. Add file > Upload files
3. อัปโหลด index.html ตัวใหม่
4. Commit changes
5. รอ GitHub Pages อัปเดต
